# Contributing

Keep changes agent-neutral and portable. Submit source changes without deployment identifiers or personal data. Run `npm ci`, `npm run typecheck`, `npm run lint --workspace app`, and `npm test`. For changes to Swift, plugins, entitlements or dependencies, include hosted native build evidence. Preserve existing schema compatibility or document the required minimum binary before introducing new fields. Use synthetic data in screenshots and tests.

Do not post vulnerabilities with credentials or user data in public issues. Use GitHub private vulnerability reporting when available, or describe the issue to the repository owner privately before publication.
